Karim Marucchi and I present the case for the FAIR Package Manager as a keynote at the Linux Foundation Open Source Summit. WordPress powers 40% of the web, which is a scale that makes its infrastructure critically important, and that infrastructure is now 22 years old. The events of late 2024, when WordPress.org made unilateral decisions that affected millions of sites, made it clear that a single point of control over package distribution is a governance and security risk. We explain what decentralizing responsibly looks like, what FAIR's federated model actually does, and why this matters not just for WordPress but as a model for other open source ecosystems.
